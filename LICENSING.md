All unlisted files retain their existing rights and notices. This change makes
no new grant for them and does not revoke any permissions previously granted.
In particular, it does not license:

- `backend/`, historical prototypes and unlisted demonstrations;
- the GREYC / Université de Caen research code, reports or presentation;
- the private TruthX Engine, hosted application or production configuration;
- real dossiers, personal data, source documents or private review outputs;
- photographs, logos, trademarks or other assets linked from a covered file;
- external resources and third-party works.

Access to a real review case is a separate, individually authorised activity;
the public software licence is not permission to access or redistribute it.
Public visibility of an unlisted file is not a new MIT grant.

## Provenance and contributions

The selected existing paths were reviewed at commit
`08a7e381201cf5481a08bb546565e48ed02c80c5`: their recorded Git authors are the
project lead's identities. The scope deliberately excludes the research
archives and legacy application code. Git history supports attribution; it is
not an independent chain-of-title audit of outside contracts.

For new contributions to the listed files, explicitly confirm in the pull
request that you have the necessary rights and submit the contribution under
MIT. Identify any third-party material and its terms. Existing comments or
private analyses are not retroactively relicensed. No copyright assignment is
required by this policy. A new path needs an explicit scope decision before it
is added to this list.

The citation file links here because a single repository-wide `license: MIT`
would conceal this mixed scope. Nothing here asserts an open-source release of
the complete OpenProof product or changes the ownership of private components.
